# React 模板

- 使用函数组件和 TypeScript。可从 props 或现有状态推导的值在渲染时计算，用户发起的操作放在事件处理函数中。
- 性能审查优先找串行网络请求和大依赖。按需读取 `../skills/react-best-practices/SKILL.md` 中适用于 React SPA 的规则。
- 修改此模板后运行 `npm run build`，它会先执行 `tsc` 再生成静态产物。
